## 🧠 Giới thiệu
> **TripTogether** là ứng dụng Android giúp nhóm bạn lên kế hoạch, quản lý và chia sẻ chuyến đi một cách trực quan.  
> Mọi thứ từ lịch trình, tài liệu, đến chat nhóm đều được gom vào một nơi.

## 👩‍💻 Thông tin dự án
- 📱 **Nền tảng**: Android (Kotlin)
- 🔥 **Backend**: Firebase (Auth, Realtime Database, Storage)
- 🗺️ **Maps**: Google Maps API
- 🖼️ **Image Loading**: Glide
- 🧭 **Dành cho**: nhóm đi du lịch, team building, gia đình

---

## 🚀 Tính năng chính
- 🔐 **Đăng nhập, đăng ký** bằng Firebase Authentication
- 🗺️ **Tạo chuyến đi** với: tên, quốc gia, thời gian, hình ảnh
- 👥 **Mời thành viên** tham gia bằng email
- 📆 **Lập kế hoạch theo ngày** với danh sách hoạt động
- 📂 **Quản lý tài liệu**: tải lên, xem hình và file theo từng chuyến đi
- 💬 **Chat nhóm thời gian thực** cho từng chuyến riêng biệt
- ⭐ **Đánh dấu yêu thích** các chuyến đi
- 🔎 **Tìm kiếm** theo tên hoặc quốc gia
- 📍 **Xem vị trí trên bản đồ** qua Google Maps

---

## 📦 Cấu trúc dự án
- `MainActivity` – Trang chính hiển thị danh sách chuyến đi
- `AddTripActivity` – Tạo chuyến đi mới
- `TripSummaryActivity` – Tổng quan một chuyến đi
- `TripPlanActivity` – Quản lý lịch trình theo từng ngày
- `GroupChatActivity` – Chat nhóm thời gian thực
- `DocumentsHomeActivity` – Upload / xem tài liệu
- `EditFriendsActivity` – Quản lý thành viên chuyến đi

## 🚀 Cài đặt và chạy ứng dụng
1. Clone repository về máy (Không Khuyến )
2. Mở project bằng Android Studio
3. Thêm file `google-services.json` từ Firebase vào thư mục `app/`
4. Run ứng dụng trên thiết bị Android hoặc emulator
